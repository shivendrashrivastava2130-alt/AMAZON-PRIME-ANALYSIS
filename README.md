# Prime Video Content Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Prime Video's content catalog using Microsoft Power BI. The dashboard transforms raw data into meaningful visual insights, helping users understand the distribution of movies and TV shows, content trends, ratings, genres, and country-wise availability.

## Objectives
- Analyze the distribution of movies and TV shows.
- Explore content availability across different countries.
- Identify the most common genres and categories.
- Examine content ratings and audience classifications.
- Analyze content releases over the years.
- Build an interactive dashboard for data-driven insights.

## Tools & Technologies
- **Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and calculated metrics
- **Data Visualization** — Charts, cards, maps, and interactive filters

## Key Analysis Areas
- **Content Type Analysis:** Comparison of movies and TV shows.
- **Genre Analysis:** Distribution of content across genres.
- **Release Trends:** Analysis of content released over time.
- **Ratings Analysis:** Distribution of content by maturity ratings.
- **Geographical Analysis:** Country-wise content distribution.
- **Catalog Insights:** Exploration of the platform's overall content library.

## Dashboard Features
- Interactive visualizations and filters
- KPI cards for high-level metrics
- Genre and content-type comparisons
- Time-based trend analysis
- Country-wise distribution
- An organized layout for easy interpretation

## Skills Demonstrated
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Data modeling and transformation
- DAX calculations
- Interactive dashboard development
- Business intelligence and data storytelling

## Business Value
This project demonstrates how business intelligence tools can be used to explore a streaming platform's content catalog, identify distribution patterns, and communicate insights through interactive visualizations.

## How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Refresh the dataset if required.
4. Interact with the dashboard using the available filters and visualizations.
